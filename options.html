Permissions & privacy

This extension requests only what it needs to work:

  • Storage — saves your API key and voice/model choice in the browser. Heads-up: it's stored as plain text in your Chrome profile, so anyone with access to this profile (or your synced Chrome data) can read it. Use a scoped key with a spending cap.
  • Access to api.elevenlabs.io — the only site the extension ever contacts. Your selected text and API key are sent here to generate the audio. No other domain is touched.
  • Runs on all pages — needed to detect when you select text and show the button. It does not read or transmit page content on its own. Only text you highlight and click the button on is sent, and only to ElevenLabs.

What this means for you:

  • Nothing is ever sent to the developer of this extension. There is no developer server, no analytics, and no tracking of any kind. Your text and API key go directly from your browser to ElevenLabs and nowhere else.
  • Highlighted text is sent to ElevenLabs (a third party) and is subject to their privacy policy. Don't narrate passwords or sensitive data.
  • Your API key never leaves your browser except as the auth header on requests to ElevenLabs.
  • If you sync Chrome across devices, your saved key syncs too (via your own Google account, not the developer).
How to get an ElevenLabs API key
  1. Create a free account at elevenlabs.io/sign-up.
  2. Open the API Keys page (Profile → API Keys) and click Create API Key.
  3. Scope it to what the extension uses:
    Access Level Why it's needed
    Text to Speech Access Generates the narration and the voice preview. Required.
    Voices Read Lists the available free (premade) voices.
    Models Read Loads the model list and each model's supported languages.
    User Read Powers the Check account usage button.
    Leave everything else at No Access. If a section doesn't load, enabling its access is the fix.
  4. Set a credit / character limit on the key so a leak or runaway can't drain your account.
  5. Copy the key and paste it into the field at the top of this page.

Free plan works fine here — just remember only premade voices are usable via the API on the free tier.
